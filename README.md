# Ensemble Lens

A comparison instrument for adaptive molecular dynamics, built for the
[Bio+MedVis Challenge @ IEEE VIS 2026](http://biovis.net/2026/biovisChallenges_vis/),
Track 1.

Every view places the three simulated systems (Aβ42 free, with tramiprosate, with its
metabolite SPA) side by side on shared scales, so that abstract Markov state labels can be
read as conformations, residue-level interactions, and mechanism.

**Live demo:** open `index.html` in any browser, or visit the GitHub Pages link above.

## What it is

`index.html` is a single self-contained page: no build step, no CDN, no network requests.
All data is inlined, so it runs from `file://` and survives a strict content security
policy. It is about 1.1 MB.

Eleven linked views, ordered so that each answers the question the previous one raises:

| View | Question |
|---|---|
| Conformational balance | How often does each system visit each shape? |
| Sampling coverage, genealogy | Where did the data come from? |
| Transition structure | Do the shapes interconvert? |
| Contact maps, binding site | Where does the drug sit? |
| Drug binding by residue | Which residues, above chance? |
| β-propensity, landscape | What does that do to the peptide? |

Global controls: number of Markov states (2, 3 or 4), system focus, trajectory alignment.
Every view rederives itself from these, so a claim can be tested against the choice of
model rather than taken on trust.

## The two design decisions that carry the result

**Encode relative to a reference.** The states are strongly metastable, holding 97 to 100%
of the time, so absolute transition numbers hide the drug effect almost entirely. Shown as
a difference against the free peptide, SPA's suppression of the escape route out of state 2
(2.78% to 0.43%) is immediate.

**Subtract an explicit chance baseline.** The simulation box holds 100 copies of the drug,
so raw contact is dominated by concentration and every charged residue appears to bind.
Pairing time-decorrelated drug coordinates with the same peptide conformations gives a null;
reporting observed minus null inverts the apparent result. Raw contact makes the two drugs
look alike. Chance-corrected contact separates them completely: tramiprosate engages acidic
side chains, SPA engages basic ones.

## Reproducing the data

Scripts run against the CoVAMPnet trajectory bundle (not redistributed here; see the
challenge page). Python 3.10 with `numpy`, `MDAnalysis` and `Pillow`.

```
python scripts/preprocess.py            # -> track1.json          populations, transitions, ITS
python scripts/analyze_structure2.py    # -> track1_struct2.json  DSSP, Rg, RMSF, ensembles
python scripts/analyze_pocket.py        # -> track1_pocket.json   binding poses, contacts
python scripts/analyze_correspondence.py --data track1_struct2_dense.json
python scripts/build_prototype.py       # inlines all data -> index.html
python scripts/make_paper_figures.py    # -> figures/fig2..6
```

`analyze_structure2.py` takes roughly 45 minutes over the full bundle at stride 20.

Two notes on the analysis, both of which changed a result:

- **Frames are kept by reservoir sampling** (Algorithm R, fixed seed). Keeping the first
  *N* frames instead biases every ensemble and RMSF toward the earliest adaptive-sampling
  epochs, which understated per-state flexibility by about 23%.
- **State correspondence is measured, not assumed.** `analyze_correspondence.py` compares
  matched states across systems on Cα-Cα distance matrices against a split-half sampling
  floor. Matched states are close but not identical, and the quality varies by state; the
  tool reports this per state. Scoring correspondence with β-propensity instead would be
  circular, since β is the quantity the drug is reported to change.

## Data

The challenge data is from Marques et al., *CoVAMPnet: comparative Markov state analysis
for studying effects of drug candidates on disordered biomolecules*, JACS Au 4(6), 2024.

`data/track1_correspondence.json` is included because it is small and is the basis of the
state-correspondence claim. The larger derived files are regenerated by the scripts above.
